Four Colour Theorem

A constructive colouring of planar graphs

Every planar graph G satisfies χ(G) ≤ 4. This site gathers the working material for a constructive proof: an interactive account of the classical theorem, the physical picture that suggested the argument, and a live map of the proof tree.
