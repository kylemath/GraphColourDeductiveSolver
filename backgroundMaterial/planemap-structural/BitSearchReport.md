# Stress test of the fixed one-bit observation

The precise observation is `(sigma,beta)`, where `sigma` contains the boundary colouring and its six bichromatic partitions, and `beta` says whether the minimum labelled remaining vertex belongs to the canonical `{1,3}` component meeting the boundary. Colours are canonicalised boundary-first; the rotation boundary starts at its minimum vertex. A policy knows the graph and the root, chooses only boundary-touching component swaps, and must select one action valid for every representative of its observation.

We tested every degree-five root of all 118 minimum-degree-five simple triangulations generated by Plantri at orders 12 through 20. At each graph, at least one degree-five root has a winning robust observation game. Therefore no all-roots failure of this restricted root-selecting policy was found in this range.

However, 46 of the 1,586 root instances have losing observation groups: nine at order 17 and 37 at order 20. Thus the bit does not repair every root. The first failing fixture is order 17, graph index 0, root 0; it has five losing groups. The remaining roots include successful choices. A rule which simply picks the smallest degree-five vertex consequently fails this particular observation game already on that labelled fixture. This does not rule out another root rule.

`bit-search-results.json` records all graphs and root counts, plus a complete losing-set certificate for that first failing root: each losing observation is nonterminal, and every common action has a concrete representative whose successor observation stays in the losing set. Colourings and successors are included. The script checks this closure property.

A losing robust quotient game means there is no common-action policy equipped with a strictly decreasing observation-only rank, or equivalently no policy guaranteed to terminate against an adversary allowed to choose a fresh concrete representative of the current observation after each step. It does **not** automatically disprove every actual memoryless policy on concrete colourings. Such a policy could revisit the same observation while its hidden state progresses. It does not supply a targetless full Kempe class; the separate census checks that all full classes on these fixtures contain a target.

The positive results give finite lookup certificates, not a uniform rank formula. They establish neither a root-selection algorithm with a proved polynomial bound nor a theorem beyond order 20. The bit is a directly computable observation, not a preserved invariant.

## Portable reproduction

Use Python with NetworkX installed. The scripts install nothing.

```sh
python escape.py --input ../agent1720/groups/K6_kittell.json --output results.json
python search.py --plantri /path/to/plantri --archive /path/to/plantri58.tar.gz --max-order 20 --input-dir ./census --output search-results.json
python bit-search.py --input-dir ./census --max-order 20 --output bit-search-results.json
```

The Plantri executable and source archive are supplied by the caller; `--archive` is optional and records its hash when provided. The census output directory holds the ASCII rotations. Neither research script contains a user-specific home path or temporary-directory path.
