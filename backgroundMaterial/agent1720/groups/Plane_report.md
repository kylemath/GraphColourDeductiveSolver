## Their description

feat(Combinatorics/SimpleGraph): combinatorial plane maps and Euler's formula

Partial foundation for combinatorial plane maps. Defines rotation systems with a single successor orbit at each vertex, faces as the cycles of `next ∘ Dart.symm`, and face lengths. A dartless map has one empty face.

Proves `face_next_apply`, `face_next_fst`, `face_of_eq_iff`, `face_of_face_next`, `rotation_at_val`, and `sum_face_lengths_eq_card_darts`.

The intended spherical plane map is a finite connected rotation system generated by Vertex, Grow, and Split. That generation relation is not implemented here. Euler’s formula must follow from those constructors; it is not introduced as a field or assumption.

Omitted: `euler_sphere`, `edge_bound`, `exists_degree_le_five`, `triangulation_edge_count`, `cycle_two_sides`, `neighbour_rotation`, and the tetrahedral and cycle-graph checks. Their required graph modifications, face-orbit surgery, and separation arguments have not been established. The face-length identity is proved only against the dart count here.

No colouring theorems are included. This source has not been compiled against Mathlib; it is an incomplete contribution, not a submission-ready implementation of the requested development.

## What is actually there

`RotationSystem` is a permutation of `G.Dart` that preserves the initial vertex and has one orbit on the darts out of each vertex. `faceNext` is `next ∘ Dart.symm`. A face is an orbit of that permutation. A graph with no darts gets one extra empty face, so the one-vertex map has face count 1. `sum_face_lengths_eq_card_darts` says the face lengths add up to the number of darts.

That identity is the handshaking half of the edge bound. It is not Euler’s formula. Vertex, Grow, and Split are not defined, so there is no spherical plane map and no theorem `v - e + f = 2`.

## One likely elaboration failure

`reversal` closes both inverse fields with `rfl`. In Mathlib, `Dart.symm_symm` is `Dart.ext`, not definitional equality: `Dart.symm` stores `d.adj.symm`, and applying `symm` twice is not the original proof. Those two `rfl`s should be `Dart.symm_symm`.
