# Intern A, cycle 7: the DL half of the quarter floor, a 2-swap rule

Hand only; the only data read are the pattern counts in quarter-classes.jsonl (no graph is needed for the size-4 class). Notation as in Lemma A: link x_0..x_4, repeat alpha at j and j+2, m = x_{j+1} (mu), a = x_{j+3} (A), b = x_{j+4} (B). To use HP's moves, HP's (x0,x1,x2,x3,x4) = (x_j,x_{j+1},x_{j+2},x_{j+3},x_{j+4}); F = swap of the {alpha,A}-component of x_{j+2} (contains x_{j+3}); B = swap of the {alpha,B}-component of x_j (contains x_{j+4}).

## 1. The size-4 floor class (order 22, e.g. #159 hole 19)
Link patterns (letters by first occurrence from position 0): filled abcbc (singleton a at 0); unfilled abcdb, abcbd, abcdc, one each. The filled state has degree 2 to the unfilled states by single-link swaps (data: filled degree 2, unfilled degrees 0,1,1). So the degree-0 state is the DL one. Check by pattern: from f = (a,b,c,b,c) a single-link swap gives abcdc (change x1 or x3) or abcbd (change x2 or x4), never abcdb. So **DL state = abcdb = (a,b,c,d,b): j = 4, alpha = b, mu = a (x0), A = c (x2), B = d (x3).** Its target set is F_{j+1} = F_0 = {f}, and f has singleton at 0. Consistent.
All six colour-pair swaps from the DL state (I enumerated which link vertices each touches): {a,b} touches x0,x1,x4 (one component, image equals the state renamed); {a,c} touches x0,x2 (one component, else the image would be a filled state other than f, impossible in this class); {a,d} touches x0,x3 likewise; {c,d} touches x2,x3 (image abcdb again); {b,c}: component of x1,x2 (not x4) gives abcdc; {b,d}: component of x3,x4 (not x1) gives abcbd. In HP's names these are F and B. So **F(s) = the abcdc state and B(s) = the abcbd state, both non-DL.**
**Path 1 (F, then A-B).** Swap 1 = F: the {b,c} = {alpha,A}-component containing x1 and x2 (touches link vertices x1, x2): link (a,c,b,d,b). Swap 2: the {c,d} = {A,B}-component of x1 (touches only x1; it excludes x3 because lock 2' fails): x1 from c to d: link (a,d,b,d,b) = abcbc = f.
**Path 2 (B, then A-B).** Swap 1 = B: the {b,d} = {alpha,B}-component containing x3, x4 (touches x3, x4): link (a,b,c,b,d). Swap 2: the {c,d} = {A,B}-component of x4 (touches only x4): x4 from d to c: link (a,b,c,b,c) = f.
The two non-DL states are exactly the two Lemma-A pre-images of f: F(s) lies in U_2 and goes by Case 2 into F_{2+3} = F_0, B(s) lies in U_1 and goes by Case 1 into F_{1+4} = F_0. So f has three pre-images, one per class of Lemma A (D_4, Case 2 from j=2, Case 1 from j=1), exactly the 4-to-1 floor.

## 2. The general rule
**R_F(s) := phi(F(s))** and **R_B(s) := phi(B(s))**. Explicitly: R_F = F, then swap the {A,B}-component of x_{j+2} (it ends with x_{j+2} coloured B, x_{j+3} coloured alpha, link (alpha, mu, B, alpha, B)); R_B = B, then swap the {A,B}-component of x_j (link (A, mu, alpha, A, alpha)). Both have singleton mu at x_{j+1}, so lie in F_{j+1}. Domains: by Lemma LC (lock 1' of F(s) is the same set as lock 2 of s) lock 1' of F(s) is automatic, so F(s) is non-DL iff lock 2' ({B,A}-path x_{j+4} ~ x_{j+2}) fails, and then phi uses Case 2. Mirror for B(s) with Case 1. So **R_F is defined exactly when F "kills", R_B when B kills.**
**Injectivity (why it may hold).** F is injective (Lemma O), F shifts j by +3, and phi is injective per (j, case) (Lemma A): R_F is a composite of injections landing in F_{(j+3)+3} = F_{j+1}. Same for R_B (shift +2, Case 1, F_{j+2+4}). The target position is forced, which matches the counting, and both are pre-image maps of f computable from f alone.

## 3. Where it can fail
1. **Not total.** DL states of radius >= 3 (radius 4 exists: T4) have F(s) and B(s) both DL, so no 2-swap path; a "fixed 2-swap rule" cannot exist on all of D_j. A longer rule along F-orbits lands in F_{j+3(k+1)+3}, equal to F_{j+1} only for k = 2 mod 5, so it needs the target position to be flexible; the count only needs each filled state hit at most 3 times in total.
2. **R_F and R_B may disagree** on a state where both are defined: s != s' in D_j with R_F(s) = R_B(s') would make f hit twice from D_j. In the size-4 class both give f, forced by uniqueness.
3. Collisions with phi-images from other j are harmless (different j, different sets), but the same f receiving two D_j states is not.
