## phi_A
Image pattern: f = (W,X,Y,X,Y) at i..i+4, K = {Y,Z}-component of x_{i+2}. If x_{i+4} not in K the swap gives (W,X,Z,X,Y): X repeated at i+1,i+3, so j = i+1, m = x_{i+2} (mu = Z), a = x_{i+4} (A = Y), b = x_i (B = W). A swap preserves the vertex set of every component of its own pair (a component has no neighbour of its own colours outside), so the {Z,Y}-component of m is still K and a is outside: lock 1 fails. Inverse: for s in U_{i+1} with lock 1 failing, K_m = {mu,A}-component of m contains only the link vertex m (a is outside, no other link vertex has colour mu or A); swapping K_m gives (B,alpha,A,alpha,A): filled, singleton B at i, with Z = mu absent, i.e. in F_i, and its {Y,Z} = {A,mu}-components of x_{i+2}, x_{i+4} are K_m and the component of a, different: in the domain. Both compositions are the identity (same vertex set swapped back). Domain condition "M3 short" is equivalent to the first conjunct x_{i+2} not~ x_{i+4} (the second conjunct is automatic, see M3 below). **No gap.**

## phi_B

Bijective. **No gap.** (Remark: swapping K_m instead also lands in F_{j+3}; that is the "alternative" bijection in section 2, correct.)

## R+3
s = (alpha,mu,alpha,A,B) at j..j+4, K = {alpha,A}-component of x_{j+2} (contains a). If x_j not in K: image (alpha,mu,A,alpha,B); alpha is repeated at j+3, j, so index j+3 with mu' = B (= b), A' = mu (= m), B' = A. Lock 1' = b ~ m in {B,mu}. The swap does not recolour any vertex coloured B or mu, so the {B,mu}-subgraph is literally unchanged: lock 1' holds iff lock 2 of s holds (a two-line direct proof; the document cites pd2 Corollary ii). Dichotomy L2 (R+3 pattern-changing iff lock 2): (lock 2 => x_j not in K) is the Jordan curve v m P b v, which separates x_j from x_{j+2}, x_{j+3}; K avoids the curve. (not lock 2 => x_j in K): Tait: with t1 = alpha+mu, t2 = alpha+A, t3 = alpha+B one gets A+B = t1, so pentagon edges e_j..e_{j+4} have colours t1,t1,t2,t1,t3; the pairs {alpha,A},{mu,B} have type t2, boundaries are (t1,t3)-paths with endpoints e_{j+3},e_{j+4},e_j,e_{j+1}. Matching {e_{j+3}e_{j+4}, e_je_{j+1}} cuts off b and m separately (lock 2 fails) and leaves x_j,x_{j+2},x_{j+3} in one region; matching {e_{j+4}e_j, e_{j+1}e_{j+3}} cuts off x_j and x_{j+2},x_{j+3}, and puts m,b together. So exactly: (lock 2, x_j not in K) or (no lock 2, x_j in K). Inverse: R+2 at j' = j+3 swaps the {alpha',B'} = {alpha,A}-component of x_{j'} = x_{j+3}, which is the same vertex set K; x_{j'+2} = x_j is outside K so R+2 is pattern-changing there and gives (alpha,mu,alpha,A,B) back. L1 (R+2 pattern-changing iff lock 1), mirrored with t3, matchings {e_je_{j+1}, e_{j+2}e_{j+3}} (lock 1 fails, x_{j+2} joined to x_j) and {e_{j+1}e_{j+2}, e_{j+3}e_j} (lock 1 holds, x_{j+2} separated): checked. So R+2 R+3 = id on the domain and R+3 R+2 = id on the codomain. **No gap.**
