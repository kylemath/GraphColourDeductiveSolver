Proved by hand

  • Reviewed
    Chain-parity law
    On the sphere, each step between doubly-locked states changes the number of Kempe chains by an odd amount. Independent review: correct, three small gaps fixed. 2.2M fresh checks, 0 failures. It fails off the sphere, as it should.
  • Reviewed
    Rigid isolation
    A rigid state never steps to another rigid state, so no frozen class is made only of rigid states.
  • Reviewed
    Surface edge balance (H3)
    An exact identity on closed triangulated surfaces. 44.9M checks.
  • Reviewed
    Local facts are not enough
    A 28-vertex non-planar graph where every hole-local fact holds yet a class has no filled state. So any proof must use the surface away from the hole. The graph is not 4-colourable, which the write-up must say.

Supported by data, not proved

  • Data only
    R* and the quarter floor in the frame class
    Exhaustive census to order 32 (21,931 graphs from 283M), flip searches to n = 56, fullerenes to C320. Never broken; the 1/4 floor is reached exactly but never crossed.
  • Data only
    LPC (Lock-Parity Conjecture)
    A Kempe class whose unfilled states all obey lock parity contains a filled state. Equivalent to no frozen orbits. 0 counterexamples on five surfaces, including 2,772 parity-clean cycle classes at frame-like holes.
  • Data only
    Conjecture F
    A mod-4 formula tying the chain count to Fisk's degree of the colouring. 0 failures on 70,999 sphere states. If proved, the chain-parity law follows easily.
  • Data only
    σ-escape
    The hole's α–μ swap exits every closed doubly-locked cycle (1,429 of 1,429).

Routes ruled out

  • Killed
    Small unavoidable set (Track B)
    The best proved set has 59 hole types, and the empirical minimum keeps rising. The all-6 type is forced, and nothing local handles it.
  • Killed
    All-6 holes via many holes or single orbits
    Holes don't compensate each other, and the symmetric fullerenes make every hole equivalent.
  • Killed
    Barnette-style signed sum
    No phase can flip on both lock swaps and Kempe cubes. The only candidate is local to the ring.
  • Killed
    Stream function on states
    Local features repeat as colour roles rotate. The class-level potential is just the floor restated.
  • Killed
    Per-cycle chain from 6–7 Oct
    A₃₄′, W2, Lemma S, statement (c) and universal B′ are all false at degree 6.

The gap, and what is running

  • Open
    Frozen classes whose chain count alternates
    The chain-parity law can't exclude a cycle that alternates 8, 9, 8, 9. Such cycles exist on the sphere, but so far always inside classes that also have filled states. This is the exact remaining gap.
  • Running
    Near-rigid search (Track J)
    Which global condition kills alternating 8/9 frozen classes.
  • Running
    Hand proof of Conjecture F (Track K)
    Through Fisk's degree and Euler counts on bicoloured cycles.
  • Running
    Lemma W in Lean (Track C)
    The companion to F. Together they would make the chain-parity law formal cheaply.
