# Messages between teams

A plain folder for short, addressed handoffs. File names are `YYYY-MM-DD-from-to-subject.md`.

**Naming.** The ledger and navigator team is **the Proof Navigator**. A message to it is headed "To the Proof Navigator", and its token in file names is `navigator`, for example `2026-10-04-math-to-navigator-breadcrumb-node.md`. The other tokens are `math` (the Math solutions and scale-up team) and `longtable` (Long Table).

- A message names its sender, its recipient and what it asks for. It assigns nothing: acceptance is an explicit reply, never silence.
- Reply in a new file whose name points back to the message it answers. Don't edit someone else's message.
- Cite evidence by repository path. Status words remain the Proof Navigator's.
