# Messages between teams

A plain folder for short, addressed handoffs. File names are `YYYY-MM-DD-from-to-subject.md`.

- A message names its sender, its recipient and what it asks for. It assigns nothing: acceptance is an explicit reply, never silence.
- Reply in a new file whose name points back to the message it answers. Don't edit someone else's message.
- Cite evidence by repository path. Status words remain the navigator's.
