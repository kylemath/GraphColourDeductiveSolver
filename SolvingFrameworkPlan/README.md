# SolvingFrameworkPlan

**Start here: [START-HERE.md](START-HERE.md).** It covers the team roles, the protocol, the conventions, the current state and a restart checklist.

| Folder | What goes there |
|---|---|
| `messages/YYYY-MM-DD/` | Addressed handoffs between teams, and nothing else. Naming and header rules: [messages/README.md](messages/README.md). |
| `docs/core/` | Governing plans and coordination: the execution plans, each team's work plan, the coordination plan, and proof obligations. |
| `docs/reports/` | Results, reviews and acceptances: Math reports, Lean reports, replays, counterexamples and accepted theorems. |
| `docs/working/` | Working notes, inquiries, night-swarm output, early plans, drafts and images. These are leads, not results. |
| `PATHMAP.md` | Old path → new path, for the 5 October reorganisation. |

New documents go in `docs/<core|reports|working>/`, never at this top level. Proof code and data stay in `backgroundMaterial/planemap-structural/`.
