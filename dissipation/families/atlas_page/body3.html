Discharging Rule Atlas

Four proofs of the four colour theorem in one shared format: each rule drawn as the picture it reads, each configuration drawn with its ring. Charge is in units of 1/60 of a degree-5 vertex's starting charge (60).

Symbols

Family tree of rule shapes

Every dot is one rule (a mirror pair counts once). Each rule is joined to its nearest relative, so the whole proof hangs off one tree with the fewest possible node changes in total. The centre is the rule with the fewest conditions; moving outward adds or changes conditions. Thick dark branches are single-node swaps. Click a dot to see what changed from its parent.

Nested clusters

The same tree cut at different swap sizes. The left column groups rules that can reach each other through steps of at most 6 node changes; each column to the right allows smaller steps, so every block splits into the blocks beside it. The last column is the rules themselves. Click a block to list its members and light them up in the tree above.

The rule as a hierarchy

The vertex that pays is at the top. The row below holds its neighbours in order around it, with the one that receives in the middle. The rows below that hold the outer ring: a hat sits between two neighbours and touches both, a fan belongs to one neighbour. Coloured vertices carry a condition; grey ones are present but may have any degree.

The same rule on the shared template

The template holds every position a rule in this language can mention: one hub, up to 8 neighbours, 8 hats and up to 3 fans under each neighbour, 41 positions in all. Every rule is a subgraph of it. Dashed outlines are positions this rule does not have.

Rule by rule: which degree pays which

Each band is a set of rules (mirror pairs counted once), from the sender's degree condition on the left to the receiver's on the right. Width = number of rules. Tunnels are drawn from the neighbour that pays to the neighbour that receives. 2026 rules whose sender and receiver are not adjacent are marked "at distance".
